## 🎨 Design Template: "Modern Medical Dark-Teal"

> ⚠️ **Different from Snowdonia** (which uses clean white + green):
> This template uses a **dark navy + teal + gold accent** scheme for a premium medical feel.

### Colour Palette

| Role | Colour | Hex |
|---|---|---|
| Primary Background | Deep Navy | `#0A1628` |
| Secondary BG | Dark Slate | `#112240` |
| Card BG | Midnight Blue | `#1A2F4E` |
| Primary Accent | Medical Teal | `#00BFA5` |
| Secondary Accent | Gold | `#FFD700` |
| Text Primary | White | `#FFFFFF` |
| Text Secondary | Silver | `#A8B2C1` |

### Typography
- **Headings:** Playfair Display (serif, elegant medical feel)
- **Body/UI:** Poppins (clean, modern sans-serif)

## 📊 Comparison: Snowdonia vs Sri J.J.R. Template

| Feature | Snowdonia (Reference) | Sri J.J.R. (New Template) |
|---|---|---|
| Color Scheme | Clean White + Green | Dark Navy + Teal + Gold |
| Font Style | Sans-serif simple | Playfair Display + Poppins |
| Hero | Static text on light bg | Animated gradient + particles |
| Services | Bullet list | Icon cards with hover effects |
| Stats | None | Animated counters |
| Contact | Simple form | Split layout with map |
| Animation | Minimal | Scroll-reveal + CSS transitions |

## 🚀 Deployment Instructions

### Option 1: Open Locally
```bash
start sri-jjr-physiotherapy-new.html
```

### Option 2: Deploy to Vercel (Free)
```bash
npm i -g vercel
vercel --name sri-jjr-physio
```

### Option 3: Netlify Drag & Drop
1. Go to netlify.com
2. Drag the HTML file into the deploy zone
3. Get a live URL instantly
